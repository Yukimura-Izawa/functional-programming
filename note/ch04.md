# 04 値としての関数

4章の目的は宣言型。

## 大きなストーリー

1. 関数型は、イミュータブルな値と純粋関数で書く
2. そのため、変数を書き換える for 文は使えない
3. 代わりに再帰を使う。for 文と再帰は同じ値を計算できる（上書きするか、等式で定義するかの違い）
4. 再帰という構造は同じで、違うのは「各要素に何をするか」という関数の部分だけ
5. その構造を1回だけ書いて、違う部分（関数）を引数で受け取るようにしたものが高階関数
6. 結果として関数を引数として渡すので、見た目がまさに宣言型になっている

## 詳細説明

### for 文が使えないから、再帰を使う

処理（初期値の処理とそれ以外の時の処理）

```
(1) doubleAll([])        = []                         ← 空のリストの時
(2) doubleAll(x :: rest) = (2x) :: doubleAll(rest)    ← リストの先頭とそれ以外に分けて、先頭を2倍、残りはまた doubleAll の処理をする
```

具体例

```
doubleAll([1, 2, 3])
= 2 :: doubleAll([2, 3])              ← 先頭 1 を2倍、残り [2, 3] は自分に任せる
= 2 :: (4 :: doubleAll([3]))          ← 先頭 2 を2倍、残り [3] は自分に任せる
= 2 :: (4 :: (6 :: doubleAll([])))    ← 先頭 3 を2倍、残り [] は自分に任せる
= 2 :: (4 :: (6 :: []))               ← 空なので、1行目のルールで [] になる
= [2, 4, 6]
```

### さらに深掘り：なぜ for 文 ＝ 再帰か？

| | 代入（命令型の =） | 等式（関数型の =） |
|---|---|---|
| 数学で書くと | `s ← s + x` | `s_k = s_{k−1} + x_k` |
| 意味 | 「今の s + x を、箱 s に入れよ」という命令 | 「s_k は s_{k−1} + x_k に等しい」という事実 |
| 時間 | 実行した瞬間の前と後で、s の中身が変わる | いつ見ても成り立つ |
| 名前と値 | 名前 s の値は、いつ見るかで変わる | 名前 s_k の値は、1つに決まっている |

### 再帰の構造は共通 → 高階関数

処理をする関数は違っても、再帰というその構造は共通。
ではその処理の種類を関数として受け取り、再帰を実行する高階関数も定義できる。

| 高階関数 | 骨組み | 受け取る関数 |
|---|---|---|
| map | 各要素を変換して、新しいリストを作る | 変換のしかた |
| filter | 条件に合う要素だけ残す | 条件 |
| foldLeft | 先頭から順に、1つの値にまとめる | まとめ方（と最初の値） |

## 1. map：各要素を変換する

処理

```
(1) map(f, [])        = []
(2) map(f, x :: rest) = f(x) :: map(f, rest)
```

- 例：`map(x ↦ 2x, [1, 2, 3])` → `[2, 4, 6]`
- Scala：`List(1, 2, 3).map(x => x * 2)`
- Rust：`v.iter().map(|x| x * 2).collect()`

## 2. filter：条件に合うものだけ残す

処理

```
(1) filter(p, [])        = []
(2) filter(p, x :: rest) = もし p(x) なら x :: filter(p, rest)
                           そうでなければ    filter(p, rest)
```

- 例：`filter(x ↦ x > 1, [1, 2, 3])` → `[2, 3]`
- Scala：`List(1, 2, 3).filter(x => x > 1)`
- Rust：`v.iter().copied().filter(|x| *x > 1).collect()`

例題：1 より大きい時 true

```
filter(p, [1, 2, 3])
= filter(p, [2, 3])                  ← p(1) = false なので、1 は捨てる
= 2 :: filter(p, [3])                ← p(2) = true なので、2 は残す
= 2 :: (3 :: filter(p, []))          ← p(3) = true なので、3 は残す
= 2 :: (3 :: [])                     ← 空なので終わり
= [2, 3]
```

## 3. foldLeft：1つの値にまとめる

処理

```
(1) foldLeft(s, f, [])        = s
(2) foldLeft(s, f, x :: rest) = foldLeft(f(s, x), f, rest)
```

- 例：`foldLeft(0, +, [1, 2, 3])`

  ```
  (0, [1, 2, 3]) → (1, [2, 3]) → (3, [3]) → (6, []) → 6
  ```

- Scala：`List(1, 2, 3).foldLeft(0)((sum, x) => sum + x)`
- Rust：`v.iter().fold(0, |sum, x| sum + x)`

## 4. sortBy：基準を渡して並べ替える

処理（まずは並べ替えの部品 insert）

```
(1) insert(y, [])        = [y]
(2) insert(y, x :: rest) = もし key(y) ≤ key(x) なら y :: x :: rest
                           そうでなければ           x :: insert(y, rest)
```

これを使って並べ替えの処理は

```
(1) sortBy(key, [])        = []
(2) sortBy(key, x :: rest) = insert(x, sortBy(key, rest))
```

- 例：文字数で並べる `["ccc", "a", "bb"]` → `["a", "bb", "ccc"]`

```
sortBy([ccc, a, bb])
= insert(ccc, sortBy([a, bb]))
= insert(ccc, insert(a, sortBy([bb])))
= insert(ccc, insert(a, insert(bb, sortBy([]))))
= insert(ccc, insert(a, insert(bb, [])))
= insert(ccc, insert(a, [bb]))       ← insert(a, [bb]) は a(1文字) ≤ bb(2文字) なので、a が先
= insert(ccc, [a, bb])

= insert(ccc, a :: [bb])             ← ccc(3文字) ≤ a(1文字) ? → false
= a :: insert(ccc, [bb])
= a :: insert(ccc, bb :: [])         ← ccc(3文字) ≤ bb(2文字) ? → false
= a :: bb :: insert(ccc, [])
= a :: bb :: [ccc]
= [a, bb, ccc]
```

- Scala：`List("ccc", "a", "bb").sortBy(w => w.length)`
- Rust：

  ```rust
  let mut sorted = words.to_vec();   // 関数の中で作ったコピー
  sorted.sort_by_key(|w| w.len());
  ```
