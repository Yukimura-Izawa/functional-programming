# 06 エラー処理

## 概要

失敗するかもしれない処理を、純粋関数のまま、型に正直に書くにはどうするか

→ 失敗も値として返す

5章でやった Option を本格的に使う章

### 具体的な扱う内容

エラー処理をしたい（例外や null を使わずに）

1. 失敗するかもしれない関数は、戻り値の型を Option にする
   - 失敗も None という普通の値になり、失敗の可能性が型に表れる
2. Option を返す小さな関数を、for 内包表記でつなげる
   - 成功なら中の値を使って次へ進み、どこかで None なら全体が None
3. コーナーケースを扱う
   - orElse で失敗したら代わりを試す
   - リストでは、ベストエフォートかオール・オア・ナッシングかを選ぶ
4. 失敗の理由も伝えたいなら Either を使う（Rust の Result とほぼ同じ。型引数の順番は逆）
   - for 内包表記の中身はそのままで、戻り値の型を変えるだけ

### まとめ

- 例外や null ではなく、戻り値の型を Option / Either にして、失敗も値として返す
  （失敗の可能性が型に表れるので、処理を忘れられない）
- 失敗するかもしれない処理は for 内包表記でつなぐ（失敗は自動で最後まで伝わる）
- 理由まで伝えたいなら Option ではなく Either（Rust の Result）
- 失敗したときにどうするかは人が判断する
  - 1件なら：orElse で代わりを試す
  - リストなら：ベストエフォート（成功したものだけ残す）か、オール・オア・ナッシング（1つでも失敗したら全体を失敗にする）

## 1. 失敗を値にする：例外を投げる関数を、Option を返す関数に書き直せる

1. 失敗しうる箇所を見つける
2. 戻り値の型を A から Option[A] に変える
3. 失敗しうる箇所で、例外の代わりに None を返す

### 例題

"Breaking Bad (2008-2013)" から開始年 2008 を取り出す関数

```scala
def extractYearStart(rawShow: String): Int = {
  val bracketOpen = rawShow.indexOf('(')
  val dash        = rawShow.indexOf('-')
  Integer.parseInt(rawShow.substring(bracketOpen + 1, dash))
}
```

### 手順1：失敗しうる箇所を見つける

使っている Java の道具には、それぞれ失敗のしかたがあります。

| 道具 | 失敗するとき | 何が起きるか |
|---|---|---|
| `indexOf(文字)` | 文字が見つからない | `-1` を返す（3章のノートで見たもの） |
| `substring(開始, 終了)` | 位置が `-1` だったり順番が逆だったりする | 例外が飛ぶ |
| `Integer.parseInt(文字列)` | 数字ではない文字列が来る | 例外が飛ぶ |

以下のように失敗する

| 入力 | 結果 |
|---|---|
| `"Breaking Bad (2008-2013)"` | 2008 |
| `"Chernobyl (2019)"` | `-` がないので dash = -1 → substring で例外 |
| `"The Wire 2002-2008"` | `(` がないので位置がずれ、parseInt で例外 |
| `"Breaking Bad (abc-2013)"` | `"abc"` は数字ではないので parseInt で例外 |

呼び出される戻り値の型はIntのままなので失敗の可能性に気づけない

### 手順2・3：Option に書きなおす

```scala
def extractYearStart(rawShow: String): Option[Int] = {
  val bracketOpen = rawShow.indexOf('(')
  val dash        = rawShow.indexOf('-')
  if (bracketOpen != -1 && dash > bracketOpen + 1)        // 位置が正しいか先に確認
    rawShow.substring(bracketOpen + 1, dash).toIntOption  // 数字でなければ None
  else
    None                                                  // 位置がおかしければ None
}
```

変えたのは次の3か所

- 戻り値の型：Int から Option[Int]
- substring の失敗：呼ぶ前に位置を確認し、おかしければ None を返す。こうすると例外が起きる状況にそもそも入らない。
- parseInt の失敗：例外を投げる Integer.parseInt の代わりに、Option を返す toIntOption を使う。成功なら Some(2008)、失敗なら None です。

エラーを考慮した後の結果

| 入力 | 結果 |
|---|---|
| `"Breaking Bad (2008-2013)"` | `Some(2008)` |
| `"Chernobyl (2019)"` | `None` |
| `"The Wire 2002-2008"` | `None` |
| `"Breaking Bad (abc-2013)"` | `None` |

### 呼び出す側での変化

戻り値が Option[Int] になったので、そのまま整数として使おうとするとコンパイルエラーになる

```scala
extractYearStart(s) + 1    // エラー：Option[Int] に + 1 はできない
```

これは「エラーを関数のシグネチャで知らせる」ということを意味する。

### Rust では

標準ライブラリが最初から Option を返すように作られているので、同じ処理がもっと短く書ける

```rust
fn extract_year_start(raw: &str) -> Option<i32> {
    let open = raw.find('(')?;   // '(' が見つからなければ None
    let dash = raw.find('-')?;   // '-' が見つからなければ None
    if dash <= open + 1 {
        return None;             // 順番がおかしい、または中身が空なら None
    }
    raw[open + 1..dash].parse().ok()   // 数値にできなければ None
}
```

- find は、Java の indexOf のように -1 を返すのではなく、`Option<usize>` を返す。見つからないことが最初から型に表れている。
- `parse()` は Result を返すので、`.ok()` で Option に変えている。

### まとめ

| | 例外を投げる版 | Option を返す版 |
|---|---|---|
| 戻り値の型 | `Int` | `Option[Int]` |
| 失敗の伝え方 | 例外（関数から別の出口で飛び出す） | None という普通の値 |
| 型を見て失敗に気づけるか | 気づけない | 気づける |
| 処理を忘れたとき | 実行時に落ちる | コンパイルエラーになる |

## 2. 小さな関数を合成する：Option を返す小さな関数を for 内包表記でつなげて、どこで None になったら全体が None になるかを追える

### 例：小さな関数を3つ用意する

```scala
// タイトル：'(' より前の部分
def extractName(rawShow: String): Option[String] = {
  val bracketOpen = rawShow.indexOf('(')
  if (bracketOpen > 0) Some(rawShow.substring(0, bracketOpen).trim)
  else None
}

// 開始年：'(' と '-' の間（前の節で作ったもの）
def extractYearStart(rawShow: String): Option[Int] = { ... }

// 終了年：'-' と ')' の間
def extractYearEnd(rawShow: String): Option[Int] = {
  val dash         = rawShow.indexOf('-')
  val bracketClose = rawShow.indexOf(')')
  if (dash != -1 && bracketClose > dash + 1)
    rawShow.substring(dash + 1, bracketClose).toIntOption
  else None
}
```

### for 内包表記でつなぐ

結果を入れる型を用意

```scala
case class TvShow(title: String, start: Int, end: Int)
```

case class は、Scala で「値をまとめた不変のデータ型」を定義する書き方。
Rust の struct にあたる。`TvShow("Breaking Bad", 2008, 2013)` のように書くと値が作れる

小さな関数を for 内包表記でつなぐ

```scala
def parseShow(rawShow: String): Option[TvShow] =
  for {
    name      <- extractName(rawShow)
    yearStart <- extractYearStart(rawShow)
    yearEnd   <- extractYearEnd(rawShow)
  } yield TvShow(name, yearStart, yearEnd)
```

- 引数：番組の文字列
- 戻り値：`Option[TvShow]`

ここでの `<-` は「Some なら中身を取り出して次の行へ進む。None ならそこで止まって、全体が None になる」という意味

ここで起こっているのは5章での flatMap や map の引数が Some() になり、さらに output も Some になったということ。
（List で `[]` だったところが None に、`[x]` だったところが `Some(x)` になっただけ）

```
flatMap(f, None)    = None
flatMap(f, Some(x)) = f(x)

map(f, None)        = None
map(f, Some(x))     = Some(f(x))
```

### 実例

成功する場合：`"Breaking Bad (2008-2013)"`

```
extractName      → Some("Breaking Bad")  → name = "Breaking Bad" で次へ
extractYearStart → Some(2008)            → yearStart = 2008 で次へ
extractYearEnd   → Some(2013)            → yearEnd = 2013 で次へ
yield            → Some(TvShow("Breaking Bad", 2008, 2013))
```

途中で失敗する場合：`"Chernobyl (2019)"`

```
extractName      → Some("Chernobyl")     → name = "Chernobyl" で次へ
extractYearStart → None                  → ここで止まる。全体が None
（extractYearEnd は呼ばれない）
```

### Rust では

and_then（Rust での flatMap）を使った形で書く

```rust
struct TvShow {
    title: String,
    start: i32,
    end: i32,
}

fn parse_show(raw: &str) -> Option<TvShow> {
    extract_name(raw).and_then(|title|
        extract_year_start(raw).and_then(|start|
            extract_year_end(raw).map(|end| TvShow { title, start, end })))
}
```

上の flatMap の入れ子と同じ形。これを `?` 演算子で書くと、for 内包表記と同じように上から順に読める

```rust
fn parse_show(raw: &str) -> Option<TvShow> {
    let title = extract_name(raw)?;        // None ならここで関数全体が None を返す
    let start = extract_year_start(raw)?;
    let end = extract_year_end(raw)?;
    Some(TvShow { title, start, end })
}
```

小さな関数の Rust 版は次のとおり

```rust
// タイトル：'(' より前の部分
fn extract_name(raw: &str) -> Option<String> {
    let open = raw.find('(')?;
    let name = raw[..open].trim();
    if name.is_empty() { None } else { Some(name.to_string()) }
}

// 開始年：'(' と '-' の間（前の節で作ったもの）
fn extract_year_start(raw: &str) -> Option<i32> {
    let open = raw.find('(')?;
    let dash = raw.find('-')?;
    if dash <= open + 1 {
        return None;
    }
    raw[open + 1..dash].parse().ok()
}

// 終了年：'-' と ')' の間
fn extract_year_end(raw: &str) -> Option<i32> {
    let dash = raw.find('-')?;
    let close = raw.find(')')?;
    if close <= dash + 1 {
        return None;
    }
    raw[dash + 1..close].parse().ok()
}
```

### まとめ

| | Scala | Rust |
|---|---|---|
| 1つずつ失敗しうる小さな関数 | Option を返す関数 | Option を返す関数 |
| つなぐ（明示的な形） | flatMap / map の入れ子 | and_then / map の入れ子 |
| つなぐ（読みやすい形） | for 内包表記 | `?` 演算子 |
| どこかで失敗したら | 全体が None | 全体が None |

### Rust メモ

#### and_then について

```rust
match 何か {
    None => None,
    Some(x) => 次の処理,
}
```

この「None ならそのまま None、Some なら中身を次へ渡す」という形を、1語にしたものが and_then

#### map について

```rust
match 何か {
    None => None,
    Some(x) => Some(普通の値),
}
```

Some なら中身を使って普通の値を作り、Some で包む。これを1語にしたものが map。

## 3. コーナーケースを扱う：orElse, 一部失敗したときどうするか

- orElse の引数と戻り値が説明できる
- ベストエフォートとオール・オア・ナッシングを、それぞれどう書くかが分かる（本では、これまでに習った道具で書く）
- 場面に応じてどちらを選ぶか判断できる

### orElse について

上のケースで、"Chernobyl (2019)" が None になった。
年が1つしかなく、- がないから。
でもこれは不正なデータではなく、「2019年に始まって2019年に終わった番組」。
正しく `TvShow("Chernobyl", 2019, 2019)` にしたいところ

解決手法

「年が1つだけの形」を取り出す小さな関数を足す

```scala
// 年が1つだけ："(2019)" の形。'-' がないときだけ成功する
def extractSingleYear(rawShow: String): Option[Int] = {
  val dash         = rawShow.indexOf('-')
  val bracketOpen  = rawShow.indexOf('(')
  val bracketClose = rawShow.indexOf(')')
  if (dash == -1 && bracketOpen != -1 && bracketClose > bracketOpen + 1)
    rawShow.substring(bracketOpen + 1, bracketClose).toIntOption
  else None
}
```

次に、「開始年の形で失敗したら、年が1つの形を試す」と書く。これが orElse

```scala
def parseShow(rawShow: String): Option[TvShow] =
  for {
    name      <- extractName(rawShow)
    yearStart <- extractYearStart(rawShow).orElse(extractSingleYear(rawShow))
    yearEnd   <- extractYearEnd(rawShow).orElse(extractSingleYear(rawShow))
  } yield TvShow(name, yearStart, yearEnd)
```

### orElse の受け取るもの・返すもの

```
orElse(Some(x), 代わり) = Some(x)     ← 成功していれば、そのまま使う
orElse(None,    代わり) = 代わり      ← 失敗していたら、代わりを使う
```

- 受け取るもの：opt（`Option[A]`）と、代わりの `Option[A]`
- 返すもの：`Option[A]`
  - opt が Some なら、opt をそのまま返す（代わりは使わない）
  - opt が None なら、代わりを返す

素直に書くと

```scala
opt match {
  case Some(v) => Some(v)
  case None    => 代わり
}
```

and_then / flatMap が「成功したら次へ進む」なのに対して、orElse は「失敗したら別の道を試す」道具

### リスト全体の扱い方を決める

問題

parseShow は文字列1つを解析する関数。
文字列のリストに map でかけると、結果は `List[Option[TvShow]]` になる

```
map(parseShow, ["Breaking Bad (2008-2013)", "Chernobyl (2019)", "abc"])
= [Some(BB), Some(Ch), None]          ← BB, Ch は TvShow の略
```

一部だけ None が混ざっているこの状態から、最終的に何を返すかを決める必要がある。方針は2つ

#### 方針1：ベストエフォート（失敗したものは捨てる）

```scala
def parseShows(rawShows: List[String]): List[TvShow] =
  rawShows.map(parseShow).flatMap(o => o.toList)
```

toList は、Option を「0個か1個のリスト」に変える関数

```
toList(None)    = []
toList(Some(x)) = [x]
```

flatMap で連結すると、None だったものは `[]` なので消える

```
flatMap(toList, [Some(BB), Some(Ch), None])
= [BB] ++ [Ch] ++ []
= [BB, Ch]
```

#### 方針2：オール・オア・ナッシング（1つでも失敗したら全体を失敗にする）

foldLeft を使う。「ここまでの結果」と「新しい1件」を受け取って、どちらかが None なら None にする関数を用意する

```scala
def addOrResign(parsedShows: Option[List[TvShow]],
                newParsedShow: Option[TvShow]): Option[List[TvShow]] =
  for {
    shows      <- parsedShows
    parsedShow <- newParsedShow
  } yield shows.appended(parsedShow)    // appended：末尾に足した新しいリストを返す

def parseShows(rawShows: List[String]): Option[List[TvShow]] = {
  val initialResult: Option[List[TvShow]] = Some(List.empty)
  rawShows.map(parseShow).foldLeft(initialResult)(addOrResign)
}
```

- addOrResign の引数：ここまでの結果 `Option[List[TvShow]]` と、新しい1件 `Option[TvShow]`
- addOrResign の戻り値：新しい1件を足した結果 `Option[List[TvShow]]`

手順

```
foldLeft(Some([]), addOrResign, [Some(BB), Some(Ch), None])   ← foldLeft(初期値, まとめ方, リスト)
→ addOrResign(Some([]),       Some(BB)) = Some([BB])
→ addOrResign(Some([BB]),     Some(Ch)) = Some([BB, Ch])
→ addOrResign(Some([BB, Ch]), None)     = None       ← ここで失敗
→ None
```

#### どちらを選ぶか

| 方針 | 戻り値の型 | 失敗があったとき | 向いている場面 |
|---|---|---|---|
| ベストエフォート | `List[TvShow]` | 失敗したものが静かに消える | 表示できるものだけ表示すればいい場面（一覧画面など） |
| オール・オア・ナッシング | `Option[List[TvShow]]` | 全体が None | 1件でも欠けると困る場面（データの取り込み、集計など） |

### Rust では

#### A. orElse

Rust では or_else。
代わりの処理をクロージャ `|| ...` で渡す。
クロージャにしているのは、最初が None のときだけ代わりを計算するため（すぐ計算してよい値なら `or(...)` も使える）

```rust
// 年が1つだけ："(2019)" の形
fn extract_single_year(raw: &str) -> Option<i32> {
    if raw.contains('-') {
        return None;
    }
    let open = raw.find('(')?;
    let close = raw.find(')')?;
    if close <= open + 1 {
        return None;
    }
    raw[open + 1..close].parse().ok()
}

fn parse_show(raw: &str) -> Option<TvShow> {
    let title = extract_name(raw)?;
    let start = extract_year_start(raw).or_else(|| extract_single_year(raw))?;
    let end = extract_year_end(raw).or_else(|| extract_single_year(raw))?;
    Some(TvShow { title, start, end })
}
```

#### B-1. ベストエフォート

Rust の Option は、そのまま「0個か1個のイテレータ」として扱える（Scala の toList にあたる）。
そのため flat_map でそのまま展開できる

```rust
fn parse_shows(raws: &[&str]) -> Vec<TvShow> {
    raws.iter()
        .map(|r| parse_show(r))     // Option<TvShow> が並ぶ
        .flat_map(|o| o)            // Option を 0個か1個として展開。None は消える
        .collect()
}
```

この「map して None を捨てる」には専用の filter_map があり、普段はこちらを使う。

## 4. 理由を伝える：Option で書いた処理を Either に書き直せる（None の代わりに Left(エラーの説明) を返す）

### Option はなぜ失敗したかを言えない

```
parseShow("(2008-2013)")       = None    ← タイトルがない
parseShow("Chernobyl (abc)")   = None    ← 年が数字ではない
```

どちらも None になる（何がダメかわからない）

### Either：失敗の中身を持てる型

- `Right(値)`：成功（right ＝「正しい」と覚える）
- `Left(エラー)`：失敗。エラーの説明を持つ

Option との対応

| Option | Either |
|---|---|
| `Some(x)` | `Right(x)` |
| `None` | `Left(エラーの説明)` |

### 関数を書き換える

これまで扱ってきた関数を None の代わりに Left を返すように書き換える

```scala
def extractName(rawShow: String): Either[String, String] = {
  val bracketOpen = rawShow.indexOf('(')
  if (bracketOpen > 0) Right(rawShow.substring(0, bracketOpen).trim)
  else Left(s"Can't extract name from $rawShow")
}

def extractYearStart(rawShow: String): Either[String, Int] = {
  val bracketOpen = rawShow.indexOf('(')
  val dash        = rawShow.indexOf('-')
  if (bracketOpen != -1 && dash > bracketOpen + 1) {
    val yearStr = rawShow.substring(bracketOpen + 1, dash)
    yearStr.toIntOption.toRight(s"Can't parse $yearStr")
  } else Left(s"Can't extract start year from $rawShow")
}

def extractYearEnd(rawShow: String): Either[String, Int] = {
  val dash         = rawShow.indexOf('-')
  val bracketClose = rawShow.indexOf(')')
  if (dash != -1 && bracketClose > dash + 1) {
    val yearStr = rawShow.substring(dash + 1, bracketClose)
    yearStr.toIntOption.toRight(s"Can't parse $yearStr")
  } else Left(s"Can't extract end year from $rawShow")
}

def extractSingleYear(rawShow: String): Either[String, Int] = {
  val dash         = rawShow.indexOf('-')
  val bracketOpen  = rawShow.indexOf('(')
  val bracketClose = rawShow.indexOf(')')
  if (dash == -1 && bracketOpen != -1 && bracketClose > bracketOpen + 1) {
    val yearStr = rawShow.substring(bracketOpen + 1, bracketClose)
    yearStr.toIntOption.toRight(s"Can't parse $yearStr")
  } else Left(s"Can't extract single year from $rawShow")
}
```
